# ECHO – Multi Department Query Handling System

ECHO is an AI-powered query management system designed to handle and route user queries across multiple departments. The system generates intelligent responses, categorizes queries based on department, and provides developers with relevant technical solutions using AI assistance.

The goal of ECHO is to simplify internal knowledge access by automatically summarizing queries, generating contextual responses, and organizing information in a structured way.

---

## Features

* **AI-Driven Query Responses**
  Automatically generates contextual responses for user queries using AI.

* **Department Based Query Routing**
  Filters and categorizes queries by department to ensure the correct team receives the request.

* **Query Summarization**
  Condenses long user queries into concise reports within a defined time frame.

* **Developer Assistance**
  Helps developers quickly access relevant technical solutions and documentation.

* **Centralized Query Handling**
  Provides a unified platform to manage, process, and analyze queries across teams.

## System Architecture

The application follows a typical full-stack architecture:

1. **Frontend (React)**
   Handles the user interface for submitting queries and viewing responses.

2. **Backend (Node + Express)**
   Processes incoming requests, manages query routing, and interacts with AI services.

3. **Database (MongoDB)**
   Stores user queries, department information, and generated responses.

4. **AI Layer (Gemini)**
   Generates intelligent responses and performs query summarization.

---

## Workflow

1. User submits a query through the web interface.
2. The backend receives the request and identifies the relevant department.
3. The system sends the query to the AI model for response generation.
4. A summarizer generates a concise report of the query.
5. The response and summary are stored in the database and returned to the user.
